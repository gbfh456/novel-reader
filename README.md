# 小说阅读器（Novel Reader）

一个挂在 SillyTavern 上的小说扩展：**在酒馆里读书、找书、做总结、生成世界书**。

悬浮球打开面板，页签有书架 / 找书 / 阅读 / 备忘 / 总结 / 世界书 / 文风；阅读页左侧是目录、右侧是正文。
导入的本地书和从书源抓回来的网络书放在同一个书架里，阅读进度、书签、备忘、总结历史都跟着书走。

- 主体是纯前端扩展；可选的服务端桥接只负责转发抓取请求，不保存书的内容；书架和正文只存在浏览器 IndexedDB
- 服务端桥接是**可选的**：装了能抓 POST / 带 Cookie 的书源、批量抓章节（快很多）；不装也能搜、能读、能下载，只是慢
- 不包含任何统计、CDN 或遥测

---

## 功能一览

| 模块 | 能做什么 |
| --- | --- |
| **书架** | 列表 / 书封两种视图、分组、排序、置顶、批量管理、按书名 / 作者 / 来源搜索、未读章数、继续阅读 |
| **阅读器** | 翻页动画、字号、滑动翻页、目录分卷 / 倒序、书签、朗读、正文替换规则、整本全文搜索、阅读进度记忆 |
| **找书（书源）** | 导入 Legado / 阅读书源，并发搜所有启用源、边搜边出结果；加入书架、下载到书架、导出 TXT、换源、更新章节、缓存管理 |
| **找书（番茄小说，可选）** | 经本地番茄下载器整本抓回，切章存进书架 |
| **总结** | 整本或自选章节、字数上限、按上下文预算分层总结、失败续跑、历史记录、插入酒馆输入框 |
| **世界书** | 从正文提取角色 / 地点 / 组织等条目，分类折叠、整理合并查重、下载 JSON、继续生成角色卡 |
| **文风** | 跟随酒馆当前预设的文风条目，生成贴合这本书的文风样本 |
| **备忘** | 本书备忘 / 分组备忘，编辑、批量删除、只复制正文、导出 Markdown、从阅读位置一键新建 |

## 安装

扩展放在下面任一个位置（推荐全局）：

```
SillyTavern/public/scripts/extensions/third-party/novel-reader/
SillyTavern/data/<用户名>/extensions/novel-reader/      # 只给单个用户
```

也可以在酒馆的「扩展 → 安装扩展」里填仓库地址自动安装。放好后**刷新页面或重启酒馆**，
「扩展」页里会出现「小说阅读器」，页面右下角出现悬浮球（可拖动，位置会记住）；也可以按 `Ctrl+Shift+N` 直接开合面板。

> 目录名建议用英文 `novel-reader`：扩展 URL 会带目录名，中文在部分环境会被转义。

### 可选：装服务端桥接

桥接负责：书源抓取 `/fetch`（POST / 自定义请求头 / Cookie）、批量抓页 `/fetch-batch`、登录头 `/cookie`，以及番茄下载器转发。

```
node public/scripts/extensions/third-party/novel-reader/setup.mjs install-server
```

酒馆本身就要装 Node，所以 Windows / Linux / macOS 都是这一条；路径用 `/` 或 `\` 都可以。
按用户安装时把 `public/…` 换成 `data/<用户名>/extensions/novel-reader/…`，卸载把最后的参数换成 `uninstall`。

面板里的「抓取桥接 · 安装 / 卸载」给的就是这条 node 命令（可直接复制执行），
仓库里的 `install-server.sh` / `uninstall.sh` 只是它的壳，给习惯 bash 的人用，面板不再展示。

然后在酒馆 `config.yaml` 里确认 `enableServerPlugins: true`，重启酒馆，访问
`/api/plugins/fanqie-bridge/ping` 返回 `{"ok":true}` 即成功。

**不装也能用**：书源照常导入、搜索、加入书架后阅读、下载到书架，只是会走酒馆网页通道（只能 GET、一页一页抓），
POST / Cookie 的书源会失败。面板里会显示「抓取桥接 · 安装 / 卸载」和对应命令，装好点「刷新」提示自动收起。

## 快速上手

1. **导入本地书**：书架页拖入或选择文件（TXT / Markdown / HTML / EPUB / DOCX），自动切章。
2. **找网络书**：切到「找书」→ 搜书名或直接粘书籍页链接 → 解析出目录 → 点「加入书架」。
   加入书架只存目录和书源信息，正文在阅读页翻到哪抓到哪；想整本离线就点「下载到书架」。
3. **读**：左侧点章节，右侧翻页；读完本章继续往后翻会直接进下一章。
4. **换源**：阅读页工具栏「换源」列出全部其它书源，挑一个切过去；抓不到就再换下一个。
5. **总结 / 世界书 / 文风**：到对应页签选章节或整本，生成后可复制、下载、插入输入框。

## 找书

### 两个通道

- **书源**（默认）：导入的站点规则，搜索会并发打所有启用的书源。
- **番茄小说**（可选）：走本地下载器，没有单章接口，只能整本下载后入库。

找书页的卡片提供：**加入书架 / 下载到书架 / 导出 TXT / 关闭**（番茄卡片只有「下载并导入书架」；
粘来的链接如果没匹配到任何书源，没有「加入书架」，只能先「下载到书架」）。

### 精准搜索（只在书源通道出现）

勾上后只保留书名和关键词一致的结果，自动忽略「（精校版）」「[完结]」这类后缀和标点；
一条完全一致的都没有时会放宽成「书名以关键词开头」，并在状态栏说明。番茄通道不显示这个选项，也不会按它过滤。

### 书源

支持 Legado / 阅读 的完整字段：`searchUrl`、`ruleSearch` / `ruleBookInfo` / `ruleToc` / `ruleContent`、并发率、请求头、登录头、`jsLib` 等。

- 规则类型：CSS / 链式选择器（`class.` `tag.` `id.`、索引 `[-1]` `[0:3]`）、JSONPath、XPath、正则、`@js:`、`{{}}`、`@put` / `@get`、`##替换`
- 详情页、目录翻页（`nextTocUrl`）、正文翻页（`nextContentUrl`）、正文替换都走同一套规则
- **JS 书源**在浏览器 Worker 沙箱里执行；`java.ajax` 这类联网调用通过桥接
- 搜索结果按「书名 + 作者」合并，同一本书多个来源合成一行，卡片上可切换来源链接

**书源管理**：

| 操作 | 说明 |
| --- | --- |
| 导入 | JSON 粘贴 / 本地文件 / 剪贴板 / 订阅链接（服务端抓取）/ 新建；单条、数组、Legado 导出包都支持 |
| 编辑 | 表单改名称、地址、分组、类型、并发率、搜索与发现地址、请求头；规则用 JSON 编辑 |
| 分组 / 筛选 | 一个源可属多个分组，下拉带数量 |
| 启用 / 停用 / 删除 | 单条或批量 |
| 校验 / 调试 | 依次跑搜索 → 详情 → 目录 → 正文，看耗时、命中数、错误；还能执行登录 JS 把 Cookie 写进桥接 |

**发现**：书源写了发现地址时，可以按分类浏览，结果与搜索共用列表。

### 加入书架之后

- **更新章节**：按章节 URL 比对新增，写未读数；打开书后清零
- **缓存管理**：缓存前 N 章 / 全部未缓存 / 清空缓存；已缓存章节带 ✓，换源会清空缓存
- **换源**：弹窗列出**全部其它书源**，每行标状态（同名书 / 没搜到 / 搜索失败），点「切换」就用它抓目录；
  抓到才换过去，抓不到那行标红、可以继续换下一个。没同名书的源会列出它搜到的前 5 本让人挑
- **编辑信息**：书名、作者、分类、封面、简介

### 番茄小说（可选）

番茄正文只能经本地「番茄小说下载器」获取（默认 `http://127.0.0.1:18423`），浏览器直接请求会被跨域拦下，
所以需要桥接转发。流程：搜书名 → 选书目 → 「下载并导入书架」→ 下载器整本抓回 → 插件切章入库。

不装桥接 / 下载器时，把搜索通道换回「书源」即可，找书、阅读、下载、总结、世界书都不受影响。

## 阅读器

- 翻页动画：无动画 / 淡入淡出 / 横向滑动 / 覆盖翻页 / 仿真翻页
- 左右滑动翻页，上下滑到头也能翻；到本章末尾继续翻进入下一章，往回翻回到上一章最后一页
- 字号调节、阅读进度记忆、继续阅读卡片
- 目录支持分卷显示、正序 / 倒序，卷标题不可点、翻章自动跳过
- 书签：记住章节 / 页码，一键跳转或删除
- 朗读：浏览器 Web Speech，语速 0.75×–2×
- 替换净化：正则规则增删改、导入导出，作用范围可选正文 / 标题
- 整本全文搜索：列出章节、命中片段和位置，点一下跳到对应页并高亮
- 图片章节：书源正文是 HTML 时会提取图片显示；图片地址和章节一起缓存（真正显示图片仍需能访问源站）

## 书架

- 列表 / 书封两种视图，书封按书名生成配色并显示进度
- 分组：新建、改名、上下移动、删除（书回到未分组）
- 排序：阅读时间 / 更新时间 / 书名 / 手动排序，可正序倒序；置顶永远最前
- 管理：多选后批量分组、置顶、更新章节、删除；手动排序可上移 / 下移
- 顶部「继续阅读」卡片直接回到上次位置，工具栏可按书名 / 作者 / 来源 / 分组搜索
- 封面：书源带封面就用网络封面，抓不到时按书名生成一张配色封面（想换封面可在「编辑信息」里填封面地址）

## 总结

- 整本总结，或勾选章节总结（支持 Shift 连选）
- 可填总结字数上限（例如 300 / 800 / 2000）
- 按上下文预算分层总结，超出预算自动分批；某段失败不影响其它段，之后可以「补充失败段」
- 结果可以复制、下载、插入酒馆输入框、加入对应小说的本书备忘
- 每本书保留一条历史总结，新总结覆盖旧记录

## 世界书

- 从整本或选中章节提取角色、地点、组织等条目，按分类折叠展示
- 可整理条目、手动合并、自动查重合并，并一键撤销
- 下载世界书 JSON，或继续生成角色卡

## 文风

- 读取酒馆当前选用的预设，按那份预设的文风条目排版
- 生成贴合当前小说的文风样本，复制后可粘回预设；切换预设会跟着变

## 备忘录

- 本书备忘与分组备忘并列展示，分组备忘不随小说删除
- 从阅读页「备忘」按钮新建时会带上当前章节和页码，可一键回到阅读位置
- 选中条目查看、编辑、批量删除、只复制正文、导出 Markdown

## 支持的文件

| 格式 | 说明 |
| --- | --- |
| `.txt` | 自动识别 UTF-8 / GBK / GB18030 / Big5 / UTF-16 |
| `.md` / `.markdown` | 识别标题，去除常见 Markdown 标记 |
| `.html` / `.htm` | 按 h1/h2/h3 切章，提取正文 |
| `.epub` | 解析 OPF spine，保留章节顺序与标题 |
| `.docx` | 解析 `word/document.xml`，按标题样式切章 |

PDF / MOBI / AZW3 / CBZ / CBR / RAR / 7Z 暂不支持，可先用 Calibre 转成 TXT 或 EPUB。

## 数据与隐私

- 小说原文、章节缓存、阅读进度、书签、备忘、总结历史、世界书结果都存在浏览器 IndexedDB（`sillytavern-novel-reader`）
- 只有点「开始总结」「生成世界书」「生成文风」时，所选章节文本才会发送到你当前配置的模型接口；备忘不会发给模型
- 网络找书是唯一的外部请求来源：只在你搜索、打开链接、阅读翻页、下载、导出时，向**你自己配置的书源 / 链接 / 代理**发请求
- 没有任何外部统计、CDN 或遥测

## 常见问题

**看不到悬浮球？**
先在「扩展」页确认「小说阅读器」已启用，再刷新页面或重启酒馆；目录名建议用英文。

**书源搜不到 / 某些源一直失败？**
先看状态栏：失败会点名具体书源和原因。桥接没装时只有 POST / Cookie 的源会失败，纯 GET 的源照常，只是慢。
单个源的问题可以在「书源管理 → 调试」里看是哪一段（搜索 / 详情 / 目录 / 正文）不对。

**换源列表是空的？**
换源会重新搜一遍其它源，打开时先把所有源列出来并逐行标状态；点某个源「切换」会现场只搜这个源。
一个候选都没有通常是这些源都搜不到这本书，或源本身抓不通——行上的提示会写明原因。

**章节抓下来是「转码失败 / 请换源」？**
站点把反爬提示页当正文返回了。插件会识别这类错误页并判本章失败、不写进书架；连续几章都不是正文会提前停下并说明原因，换源即可。

**下载很慢？**
默认走酒馆网页通道，一章一页。装桥接后会走 `/fetch-batch` 批量抓，快得多；也可能是站点限速，换源更实际。

**封面不显示？**
网络封面抓不到时会自动退回按书名生成的封面；想指定封面，用书架卡片「更多 → 编辑信息」填封面地址。

## 开发与自检

```
node dev/test-node.mjs                 # 单元测试（解析、规则、书架、总结、世界书等）
NODE_PATH=/tmp/pwtest/node_modules node dev/harness-search-ui.cjs   # 浏览器 harness 示例
```

`dev/harness.html` 提供手动自检台：`?autotest=online` 跑「搜索 → 加入书架 → 抓正文」链路，
其余 harness 覆盖换源、批量抓取、并发、停止、错误页识别等场景。测试台只用于开发，不参与扩展运行。
